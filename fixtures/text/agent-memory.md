# Agent Memory

Local learning agents remember **evidence**, not vibes.

## What gets stored

- Validated learner explanations from Probe sessions
- Concept mastery transitions backed by append-only learning events
- Source citations resolved to indexed blocks in your library

## What stays out

- Raw API keys (OS-backed secret storage only)
- Unverified model claims without block-level citations

## Golden path demo

1. Import this note into a Studio.
2. Ask what the agent remembers versus what it cites.
3. Complete a Probe to persist demonstrated understanding.

The Learning Map should reflect evidence — not chat history alone.
