# Changelog

All notable changes to Omakase are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 0.1.0 — 2026-07-31

### Added

- Local-first Electron learning studio (Studios, Inbox, Today, You)
- Source ingestion for text/Markdown, PDF, and web capture
- Local FTS5 + embedding retrieval with citation-validated Learn mode
- Adaptive Probe learning loop with Learning Map and next actions
- BYOK providers: OpenAI, Anthropic, OpenRouter (plus deterministic mock)
- Browser capture extension (Chrome / Edge MV3)
- Backup, restore, and diagnostics export
- Public landing page (`website/`)
- Contributor docs, security policy, and release scripts
